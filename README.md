This repository contains the source code for Cosmic Conquest, a fun learning project designed to explore game development on the [Solana] blockchain. 

[Solana]: https://solana.com/

## Project Structure

The project is divided into two main components. Please refer to their specific documentation for setup and usage instructions:

- **[Frontend Client (Next.js)](app/README.md):** The web-based player interface located in the `app/` directory.
- **[Game Engine (Anchor/Rust)](programs/game_engine/README.md):** The on-chain game logic and state management located in the `programs/game_engine/` directory.

## Quick Start

To build and test the entire project from the root directory:

```bash
yarn install
anchor build
anchor test
```
